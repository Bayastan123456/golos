# Голос — тренировки речи

Монорепозиторий с приложением React/Vite (`golos/`) и API NestJS/Prisma
(`golos-api/`). PostgreSQL хранит аккаунты и результаты тренировок.

## Локальная разработка

В каждой папке выполнить `npm ci`. Создать локальные `.env` на основе
`.env.example`, указав свои значения. Секреты не коммитить.
В API: `npm run build`, применить миграции Prisma и при необходимости seed,
затем `npm run start:dev`. В приложении: `npm run dev`.

Whisper и Ollama устанавливаются отдельно. Их исходники, модели и локальная
база не входят в репозиторий. Адреса сервисов задаются в окружении API.

## Размещение

Для двух проектов Vercel выбрать Root Directory `golos` и `golos-api`
соответственно. Деплой API на Vercel требует отдельной адаптации лимитов
к нескольким экземплярам, размера аудио и проксирования авторизации.
Текущая проверенная серверная конфигурация рассчитана на один процесс API.
PostgreSQL подключается через провайдера (например, Neon), данные БД
не хранятся на GitHub. Перед публичным запуском выполнить оставшиеся проверки.

Подробности: [проверка готовности](PRODUCTION_REVIEW.md),
[размещение на сервере](deploy/README.md).
