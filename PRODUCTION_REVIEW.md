# Golos: исправления после проверки

10 ноября 2026. Найденные ошибки кода исправлены. Публичный выпуск требует
проверки инфраструктуры и полного сценария на staging.

## Исправлено

- Все четыре ошибки React effects без отключения правил ESLint. Обновления
  состояния выполняются в обработчиках событий и ответов API. Сохранены отмена
  запросов и защита прогресса от данных другого аккаунта.
- Дополнительная защита от устаревших ответов авторизации и словаря.
- Вход: 5 попыток/мин с IP; регистрация: 3/час с IP, Retry-After при превышении.
- ИИ: 12 запросов/мин на пользователя, максимум 2 одновременные задачи и одна
  на пользователя. Место резервируется до загрузки файла и освобождается также
  при ошибках. Таблица лимитов ограничена 10 000 ключами.
- Запись автоматически останавливается через 10 минут; размер ограничен 10 МБ,
  слишком большая запись не отправляется на API. Добавлена поддержка audio/ogg
  на странице ИИ-тренера и описание лимитов.
- .env.production задаёт /api. Сборка отклоняет localhost/HTTP адрес внешнего API.
  После исправления проверенная production сборка не содержит localhost:3000.
- WHISPER_URL настраивается окружением. Production требует HTTPS FRONTEND_URL
  и реальный JWT_SECRET; Secure cookie вычисляется после загрузки окружения.
- HOST по умолчанию 127.0.0.1, TRUST_PROXY настраивается для доверенного прокси.
  Добавлены graceful shutdown, таймаут подключения и запросов PostgreSQL.
- /api/health/ready проверяет БД и возвращает 503 при её отказе.
- Build генерирует Prisma Client; start:prod задаёт NODE_ENV=production.
- HTTP setup вынесен в общую функцию, чтобы тесты использовали реальные
  CORS, проверку Origin, ValidationPipe, cookie parser и префикс /api.
- Шаблонный e2e заменён 5 сценариями: readiness/авторизация, регистрация и cookie,
  валидация и запрет чужого Origin, сохранение/изоляция прогресса, вход/выход.
  Тесты требуют отдельную мигрированную БД через TEST_DATABASE_URL.
- Добавлены шаблоны nginx и systemd: HTTPS, SPA fallback, прокси /api,
  корректные заголовки IP, лимит запросов, upload limit и таймауты моделей.
- Убрана неверная надпись об OpenAI из интерфейса.

## Подтверждённые проверки

- Frontend: ESLint, TypeScript и Vite build.
- API: oxlint, Prisma generate, Nest build, полная проверка TypeScript, включая test/.
- 14 unit-тестов: базовый контроллер, ответ/сбой Ollama, readiness БД, ограничения
  входа/регистрации/ИИ, освобождение слотов при успешном и аварийном завершении.
  Инициализация всех HTTP-модулей и зависимостей также проверена без реальной БД.

## Что нельзя считать проверенным

- Интеграционные тесты: TEST_DATABASE_URL не задан, поэтому suite остановлен
  с явным сообщением. Прогона успешных e2e нет. Запуск также требует среду,
  разрешающую PostgreSQL-соединения и локальный HTTP-сервер.
- npm audit: в текущей среде registry.npmjs.org недоступен. Нет подтверждения
  отсутствия уязвимых зависимостей; выполнить аудит до выпуска.
- Сервер размещения не предоставлен. PostgreSQL, модели, ffmpeg, сертификат,
  домен, автозапуск, backups и восстановление проверяются на целевом сервере.
- Шаблоны nginx/systemd не устанавливались и не проверены на конкретном сервере.
- Полный браузерный прогон, Safari/mobile, реальная работа микрофона и моделей,
  производительность под нагрузкой пока не подтверждены.

## Ограничение архитектуры

Лимиты в памяти рассчитаны на один процесс API и одну пару сервисов моделей.
Для нескольких реплик нужны общие счётчики и распределённое ограничение задач.
Не запускать cluster поверх этой конфигурации без такой доработки.
Официальная справка о доверии к прокси:
https://expressjs.com/en/guide/behind-proxies/

Порядок размещения и запуска тестов: deploy/README.md.
